# Plan: Initialize Supabase Database via SQL Script

Create a single `sql/init.sql` script to run in the Supabase SQL editor that creates all **13 tables** documented in `docs/db-doc.md`. The 3 auth tables (`users`, `verification_codes`, `refresh_tokens`) already exist from SQLAlchemy auto-create — the script will assume `users` exists for FK references.

---

## Decisions

- **Approach:** Raw SQL script (run in Supabase SQL editor), not SQLAlchemy models
- **Scope:** Only tables in `db-doc.md` — community tables excluded
- **Auth tables:** NOT included in the script (already exist from SQLAlchemy auto-create). Script assumes `users` table exists for FK references.
- **`IF NOT EXISTS`** on all `CREATE TABLE` statements for idempotency
- **File location:** `sql/init.sql` (new directory)

---

## Steps (tables ordered by FK dependencies)

### Phase 1: Menu & Food Data (9 tables)

1. `restaurants` — standalone, no FKs
2. `meal_types` — standalone, no FKs
3. `foods` — standalone, no FKs
4. `food_icons` — standalone, no FKs
5. `menu_snapshots` — FKs → `restaurants`, `meal_types`; UNIQUE(restaurant_id, meal_type_id, service_date)
6. `menu_sections` — FK → `menu_snapshots`
7. `food_nutrition` — FK → `foods` (1:1 via UNIQUE on food_id)
8. `food_icon_assignments` — FKs → `foods`, `food_icons`; composite PK
9. `menu_section_items` — FKs → `menu_sections`, `foods`

### Phase 2: User Preferences & Tracking (3 tables)

10. `user_preferences` — FK → `users` (UNIQUE on user_id)
11. `meal_logs` — FK → `users`; UNIQUE(user_id, date, meal_type)
12. `meal_log_items` — FKs → `meal_logs`, `foods`

### Phase 3: Favorites (1 table)

13. `favorites` — FKs → `users`, `foods`; UNIQUE(user_id, combo_id)

## Column Details

All column types, constraints, and FKs are defined in `docs/db-doc.md`. Key type mappings for Supabase (PostgreSQL):

| db-doc.md Type | PostgreSQL Type |
| --- | --- |
| `INT` with Auto Increment | `INT GENERATED ALWAYS AS IDENTITY` |
| `UUID` | `UUID DEFAULT gen_random_uuid()` |
| `TIMESTAMPTZ` | `TIMESTAMPTZ DEFAULT NOW()` (where applicable) |
| `JSONB` | native `JSONB` |
| `DECIMAL(10,2)` | `NUMERIC(10,2)` |
| `BOOLEAN` | `BOOLEAN` |
